# FJ-HACNet: A Hyperbolic Adaptive Collaborative Network
[![Paper](https://img.shields.io/badge/Paper-Computers%20and%20Electronics%20in%20Agriculture-blue)](#)

This is the official PyTorch implementation of the paper **"FJ-HACNet: A Hyperbolic Adaptive Collaborative Network for Real-Time Field Flat Jujube Detection and Counting"**.
